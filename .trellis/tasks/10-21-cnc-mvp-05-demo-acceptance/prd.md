## Requirements

- 扩展既有 Vue Web，提供账号健康/待办、文件和任务创建、进度、结果、两家对比、历史、截图与 CSV。
- 展示原币、价格性质/范围、新鲜度、交期和可比性，不把缺值显示为 0 或把估价当成功。
- 冻结基准 12 项及连续每家 10 项，以真实运行报告成功率、均值/P95、墙钟吞吐、等待与人工介入。
- 完成安全、恢复、取消、重复请求、提示注入、路径/对象权限及禁止交易测试。
- 现场两家真实闭环、临时改参、一次受控故障恢复、两轮历史与代码架构讲解可复现。
- 交付部署/运行/备份恢复说明，依赖浏览器版本固定；不改动用户现有移动端环境文件。
- 参数界面从对应平台的脱敏 JSON 定义 API 读取可用子集和版本，材料/处理变更后刷新依赖项，不让 Web 持有原始站方定位器或会话。
- 展示 Workflow 业务步骤、异常/策略/复验摘要、人工待办与真实模型用量；不直接暴露原始消息/推理/checkpoint。演示包含正常报价与真实 Deep Agents 异常策略选择/受控恢复；普通人工暂停与实际 SDK interrupt 分别处理，见[Agent 设计](../10-21-cnc-pricing-mvp/agent-design.md)。

- [ ] D-01：现有 Web 可操作任务并查看报价、完整参数、证据和历史，CSV 与筛选结果一致且防公式注入。
- [ ] D-02：两家真实线上闭环、临时改参和故障恢复演示完成；录像/fixture/合成数据明确标识。
- [ ] D-03：基准 12 项关键参数/价格核对 100% 正确；连续 20 项结果可复算，未达建议指标明确列出。
- [ ] D-04：敏感泄露/越权/交易测试零缺陷；秘密不进入前端、日志、导出或模型上下文。
- [ ] D-05：至少两轮真实自动监测证据可查；备份恢复在隔离环境完成，不误发询价。
- [ ] D-06：父 AC-01～13 逐项有测试结论、证据和实测环境记录，无假定完成项。测试 TC-08/16～19/23/25～28（旧可选模型断言按 D-12 增补契约替代）及全套 P0 回归。
- [ ] D-07：两平台参数定义/状态各自正确，未知选项不能作为可用默认提交，配置版本可查，TC-CFG-07/08 与父 AC-11 完成核验。
- [ ] D-08：TC-DA-01～10、TC-WF-01～06 及 E01～E13 有结论；固定报价步骤和真实模型异常分析/策略选择/守卫/复验可演示，正常报价/Agent 恢复/人工介入统计分开。正常零模型调用有效，fixture/模型验证与平台 live 分别标记；交接版本/预算/私有 checkpoint，父 AC-12/13、MVP-R10/14/15。
