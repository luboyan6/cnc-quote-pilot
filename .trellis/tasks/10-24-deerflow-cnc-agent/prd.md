# DeerFlow Agent 源码融合与 CNC 单项目集成

> 2026-10-29 后续实施授权：用户要求实现本任务树中全部 Agent 升级任务。以下“本轮仅规划”等措辞记录此前规划阶段；现按既定子任务顺序实施，验收门禁不变。

## 目标与用户价值

将 DeerFlow 的必要 Agent 源码适配到现有 FastAPI/Vue CNC 项目，提供可停止的聊天、技能与受限业务工具，复用已有账号、报价、批量、监测和结果能力。
用户在 2026-10-29 明确要求按当前项目架构融合源码；本轮仅修改计划，所有子任务保持 planning。

## 背景与已确认事实

原 Agno 聊天、个人模型及认证仍是现有产品路径；官方 Client 尚未接入。同步 Client 未通过首 token 前停止门禁。
当前已有 CNC 报价、批量、恢复、调度和结果代码；相关任务状态及真实平台验收各自保留，不能按 10-24 的调研重复建设。
最新依据为 [源码取舍与现状](research/source-integration-replan-2026-10-29.md)。它取代 10-27 的 Client-only 方案及旧授权，历史清理记录继续保留。

## 需求

| ID | 用户可观测需求 |
| --- | --- |
| R-01 | 已认证聊天支持流式、历史续聊、工具进度和停止，跨用户隔离并兼容原客户端。 |
| R-02 | 技能目录、详情与 Agent 实际可执行技能一致；按需加载且工具执行经过当前 CNC 权限校验。 |
| R-03 | 账号凭据加密、会话复用和人工恢复保持有效；明文不进入模型、事件、日志或截图。 |
| R-04 | 已授权 STEP 与精确配置产生可核验的价格、工期和凭证，正式报价、参考估价、待审核如实区分。 |
| R-05 | 多图纸、多平台、数量 1/2/5 的组合产生独立持久子项，重试/重放不重复未知副作用。 |
| R-06 | 支持监测频率、暂停/恢复、独立轮次和可比较价格历史，同价也保留真实观测。 |
| R-07 | 超时、失效、取消、页面变化和重启有界处理；聊天停止与后台业务取消分开，不确定写入先对账。 |
| R-08 | UI/Agent 展示源记录中的状态、耗时、指标、趋势和授权凭证。 |
| R-09 | DeerFlow 必要源码按本项目分层、配置、认证和生命周期融合；交付可追溯的实际能力，无整目录搬运或独立 DeerFlow 运行服务。 |
