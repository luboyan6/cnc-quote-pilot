# 本地 DeerFlow 源码 Agent 聊天与 Vue 集成

> 2026-10-29 后续实施授权：用户要求实现全部 Agent 升级任务，本子任务按前置门禁实施；以下计划阶段范围描述保留为历史记录。

> 2026-10-30 用户澄清：旧 Agno 聊天无需迁移，旧记录继续保留。源码引擎维护自己的新会话；不以当前用户名猜测历史所有者。新会话的刷新续聊及回滚读取仍需验证。

## 目标与背景

让现有聊天消费融合在 FastAPI 内的 AgentService，支持技能/工具进度、历史续聊、附件和真实停止，保留个人模型、认证与原客户端。
对应 R-01/R-02/R-09，并提供 R-04/R-08 的文件与结果入口。2026-10-29 本轮只修订计划，取代直接调用官方 Client 的方案。

当前聊天仍在 `app/modules/ai/chat/`，使用 Agno 历史；Lead 源码融合尚未实施。新依据见 [源码与项目映射](../10-24-deerflow-cnc-agent/research/source-integration-replan-2026-10-29.md)；[旧 Client 门禁](research/in-process-client-gate-2026-10-29.md)只保留为历史事实。

## 需求

- C-01：REST/模型/旧 WS 和个人设置继续可用；源码引擎的新历史支持读取、续聊、分页/排序、重命名/删除，拒绝跨用户访问。旧 Agno 记录保留，不迁移。
- C-02：新协议显示实际图生成文本、技能激活、工具进度/失败与领域状态；首 token 前即可停止，晚到事件不串状态。
- C-03：技能列表/详情与本地 Agent 的同一目录及权限一致，前端选择对应真实可执行能力。
- C-04：STEP 先上传真实字节获取业务引用；第三方授权不默认开启，上传/发送失败保留草稿。
- C-05：关闭聊天停止本轮生成与观察，已准入后台任务继续；业务取消是独立显式操作。
- C-06：LangGraph checkpoint 是推理状态来源；应用只补会话所有者/元数据/旧历史关联与可见消息投影，融入当前项目分层，不建立第二套推理历史。

## 后续验收

- [ ] CA-01（C-01/06）：旧 Agno 记录无损保留且在旧执行器可读；源码引擎新消息刷新保留，列表/CRUD 一致无重复，第二用户拒绝；显式回滚旧执行器仍读到新可见历史。
- [ ] CA-02（C-02/05）：首 token 前/流中停止、慢消费、断线、切会话、晚到事件均准确；stop 进入后 1 秒内确认并收敛本地生成，有图/model 资源已释放证据且无重复终态。
- [ ] CA-03（C-02/03/06）：真实融合图串联移植的技能激活、中间件、受权工具、真实业务记录及 UI；失败如实显示，运行时不依赖 DeerFlowClient/Gateway。
- [ ] CA-04（C-04）：上传字节/hash/记录/引用一致，越权/未授权第三方传输不触发报价；失败保留消息/附件草稿。
- [ ] CA-05（C-01/05）：旧 Web/Uni-app WS/REST/模型回归；关闭聊天不取消已准入任务，显式业务取消只影响目标。
- [ ] CA-06（通用）：后端局部检查、Vue Vitest/type/lint/build 通过，事件/UI/日志无凭据；会话/技能/路由/资源符合当前 FastAPI 分层与生命周期。
