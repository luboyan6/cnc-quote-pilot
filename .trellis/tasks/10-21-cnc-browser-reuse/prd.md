# CNC 浏览器能力复用与 Trellis 修订

## Goal

交付供既有首平台、第二平台和监测任务共用的浏览器最小执行层，以源码证据减少重复实现，区分组件验收和真实平台验收。

## Confirmed Facts and Authorization

- 用户原始指令规定现状 → 本地源码 → 选型 → 更新任务 → 设计实现 → 测试；2026-10-21 后续明确“允许创建修订任务并推进实现，并确认与现有的 trellis 任务不冲突”。本轮执行授权不解除真实平台权限、样件和身份条件。
- 参考身份、源码与许可已核查，见 [源码分析](../../../docs/browser-reference-analysis.md)。现有 backend 无产品 CNC 执行器；原有 7 项任务无已完成项。
- 原 01 保留 live gates；02/03/04/05 保留依赖和状态。本项抽出共用浏览器能力，平台闭环、持久调度、Agent 工厂及 Web 归原任务。

## Requirements

- BR-R01：记录路径、符号、Commit、依赖、许可与复用决定；参考仓库只读。
- BR-R02：递归修订相关任务，保留 ID、状态、依赖、验收 ID 与历史；共用浏览器能力只在本项实现。
- BR-R03：账号隔离、浏览器生命周期、安全会话和登录复验；身份异常、挑战、页面不明时暂停并给出人工出口。
- BR-R04：受信适配器确定性执行参数/上传/提取；校验 STEP、回执、参数与真实金额交期，目录价格和上传完成不算报价。
- BR-R05：副作用 intent 先记录；超时、取消、重启或重复调用不盲重发；只读协调无法确认时人工处理。读取有限重试。
- BR-R06：秘密加密脱敏、不进入模型；精确域名和公网出站限制、禁止交易，不绕过验证码或权限。
- BR-R07：单元/Mock 与 Chromium 合成 E2E 覆盖正常、隔离、异常、释放；真实平台测试独立报告。
