# T4：CNC 结果展示与可比价格历史

> 状态 planning；父任务：[四模块闭环](../10-21-cnc-mvp-04-monitoring/prd.md)。依赖 T1 批次、T2 恢复及 T3 计划/轮次契约。

## 目标

用户在现有 CNC 管理界面统一查看批次、监测轮次、报价性质、可比较历史和私有截图，并能判断等待/失败原因和可执行操作。列表、统计与图表对同一筛选展示一致事实。

## 确认事实与依据

已有结果模型、统计/历史 API 和 Vue/ECharts 页面；当前 success 将正式/参考价合并，历史分组不足，统计/历史的直接查询和截图读取需统一权限。证据见 [源码核对](../10-21-cnc-mvp-04-monitoring/research/planning-revision-2026-10-28.md) 的 result/service.py:64/145、controller.py:90、quote/repository.py:328/464 和结果 index.vue:1/493。本项增量扩展这些入口。

## 需求

- V-01（父 R-03/08）：批次列表/详情显示逐项状态、尝试、排队/执行/人工耗时、进度与允许操作。
- V-02（父 R-06/08）：计划列表/编辑和轮次详情展示周期、下一执行时间、暂停原因、漏跑与关联批次。
- V-03（父 R-08）：正式报价、参考估价、待审核、失败、取消、人工等待和核对分别展示；指标分子/分母可复算。
- V-04（父 R-09）：历史按完整可比条件分组，保留同价观测；未知/不同条件不直接计算变化或画零价。
- V-05（父 R-10）：所有结果入口应用相同数据范围，截图私有且可追溯到对应执行。
- V-06（父 R-02/11）：金额精度、平台原始交期、空值和冻结参数准确呈现；原有账号与单次报价交互保持。
- V-07（父 R-04）：关闭/切换批次页面只停止观察，显式暂停/取消/重试使用当前权限与后端允许动作。

## 验收标准

- [ ] V-AC01：通过批次入口可预览、创建、查看 12 项进度；任务/计划/轮次/结果可相互定位，操作权限准确。
- [ ] V-AC02：QUOTED、REFERENCE_ESTIMATE、PENDING_REVIEW 独立计数/标识，JLC 参考价不显示为正式成功；重试不重复计子项成功。
- [ ] V-AC03：列表、统计、历史使用同一筛选与可见范围，指标分母符合共享契约；零分母显示暂无结果，耗时区间可核验。
- [ ] V-AC04：材料/数量/文件版本/币种/商业口径/报价性质不同形成独立系列；未知条件提示不可比较，不连线混比或默认补零。
- [ ] V-AC05：最近 N 个实际观测按 observed_at 展示；同价新观测保留；十进制金额往返和差额/变化率计算准确。
- [ ] V-AC06：跨用户统计、历史、详情和截图请求拒绝；证据路径越界、软删除和不存在文件明确失败，公共 static 地址不能读取新私有证据。
- [ ] V-AC07：快速切换筛选/路由/抽屉，迟到响应不恢复旧数据；轮询串行、关闭释放请求和 Blob，后台批次继续。
- [ ] V-AC08：原账号登录、参数配置和单次报价定向回归、前端类型/定向交互/生产构建及新增结果后端检查通过。

## 范围外

不重做全站 UI、不新增聊天/Agent、不自动换汇，不以单次 UI mock 代替真实平台验收。新增复杂导出、外部告警和定制 BI 报告后续处理。
