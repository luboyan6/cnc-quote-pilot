## Acceptance Criteria

- [ ] AC-01：交付环境中一份授权 STEP 从首平台取得明确真实报价；参数、金额、币种、交期对应同次页面，证据可查，未进入正式下单/支付。
- [ ] AC-02：首平台改数量或材料后重算，产生新参数与报价，不读取旧价冒充新价。
- [ ] AC-03：最终两家不同 provider_group 接通；Xometry 中国/美国或嘉立创不同入口不能独立凑两家。
- [ ] AC-04：冻结 2 文件 × 2 平台 × 数量 1/2/5 共 12 个可报价基准明细，真实报价及人工核对完成，关键字段 100% 正确。
- [ ] AC-05：每平台连续 10 项，共 20 项保留全部结果与人工介入；各≥90% 成功率、平均/P95/吞吐保持 SRS 建议目标，未实测不称已达标。
- [ ] AC-06：两轮自动定时触发产生独立有效观测，同价不覆盖，不同参数/币种/税运口径不混为严格历史比较。
- [ ] AC-07：有限恢复与接管可用；自动重试≤2，恢复/回查总 attempt≤3，提交不明不盲目重发。
- [ ] AC-08：敏感泄漏、越权及禁止交易测试零缺陷；成功结果证据可访问、可核验。
- [ ] AC-09：Web 创建跟踪任务、查看两平台报价/历史/截图、导出 CSV，并演示改参与恢复。
- [ ] AC-10：版本、实测环境、样件哈希、参数版本、报告与部署恢复说明可交接；模拟/合成/录屏不替代真实闭环。
- [ ] AC-11：Xometry US/嘉立创 CNC 读取各自 JSON 和已固定版本；材料/Finish/颜色/Roughness/附加服务等不串用 IDs，字段依赖正确。未验证选项、界面变体或提取定位不得冒充可用；网站材料 price 不计零件价；TC-CFG-01～08 有可追溯检查及实测结论。
- [ ] AC-12：固定 Workflow 正常链路和实际 Deep Agents 异常观察/分析/恢复决策均有证据；策略守卫、复验、持久恢复、注入防护、预算和幂等通过 TC-DA-01～10。正常报价允许无模型调用，真实 Agent 测试与平台 live 结果分别标记；F-08/S-07/M-08/D-08 有结论。
- [ ] AC-13：同一已核实前置/事件执行固定主步骤，E01～E13 有明确分支及恢复/停止位置；未知异常可由 Agent 选择允许策略，非法/过期/多动作策略不执行，恢复复验通过才推进。TC-WF-01～06 有结论，两家/批量/定时可追溯流程版本。

先跑通以 AC-01/02 为首交付点；仅单平台或脚手架不等于完整 MVP。

## Out of Scope

- 账号注册、实名认证、资质审批与绕过验证/反自动化/地区限制。
- 购买、支付、正式订单、自动扣款授权或账号安全设置修改。
- 任意自主浏览器动作、手写第二套 LangGraph 编排、强制 MCP/AgentSeek gateway、分布式 Browser Pool。
- 移动端、CAD 引擎、复杂装配、跨币种排名、自动邮件读取、第三家以上适配器。
- 首平台前的高级图表、Markdown 导出、动态多代理/任意模型工具和跨平台并发为 P1/P2；固定 Workflow、Deep Agents 异常恢复、策略守卫/复验为 P0。默认不开放跨业务规划/委派，异常分析仍可观察并选择受限恢复策略。
