# T2：CNC 异常分类、重试与执行恢复

> 状态 planning；父任务：[四模块闭环](../10-21-cnc-mvp-04-monitoring/prd.md)。依赖 [T1](../10-28-cnc-monitor-01-batch/prd.md) 的队列、尝试、取消与统一执行入口。

## 目标

任务发生临时故障、人工认证、远端回执丢失或进程重启时，用户能够看到可信原因和下一步；允许的自动恢复有次数和时间边界，不重复上传、保存配置或提交报价。

## 确认事实与依据

既有 Run/Intent、账号 fencing 和 WAITING_HUMAN 可复用；当前 QuoteService 在本进程之外找不到 owner 时返回不可自动重试原因。证据见 [源码核对](../10-21-cnc-mvp-04-monitoring/research/planning-revision-2026-10-28.md) 的 quote/service.py:317/323、login/repository.py:78/104 和 quote/repository.py:468/598。

## 需求

- E-01（父 R-03/05）：错误按业务阶段和副作用状态分类，返回脱敏的固定错误码和可执行提示。
- E-02（父 R-05）：临时错误有限重试，过期会话只尝试一次重新认证，限流按账号/平台冷却；资源排队不耗预算。
- E-03（父 R-05）：验证码/MFA/声明缺失进入人工等待，有超时和资源上限；显式操作复验当前文件、声明和权限。
- E-04（父 R-05）：远端回执不明仅只读核对；成功证据已取得但本地失败时只恢复持久化。
- E-05（父 R-04/05）：进程重启、取消或租约失效后，旧执行回调不能写入新尝试或撤销终态。
- E-06（父 R-03/10/11）：保留尝试、错误、阶段、时间区间和证据；后台恢复独立于前端，权限撤销及时停止。

## 验收标准

- [ ] E-AC01：网络超时、页面变更、限流、登录失效、参数错误、人工认证和结果存储失败映射为契约中的类别/状态，API 不回显原始异常。
- [ ] E-AC02：最多 3 次执行（含首次），退避与冷却持久保存；重启/手动重复点击不重置预算；排队不增次数。
- [ ] E-AC03：上传/保存/提交的 claimed/uncertain 故障窗口触发 RECONCILING；重复消息或请求不会再发远端写入。
- [ ] E-AC04：远端已确认成功但本地提交失败，只恢复本地写入/只读核对，结果最终幂等。
- [ ] E-AC05：未触发副作用的过期领取可恢复；原 worker 活跃或 lease 未过期时不得抢占；旧 token 更新被拒绝。
- [ ] E-AC06：待执行、运行、人工等待和核对期间取消均保留真实结果与 Intent；cancel/complete 竞争按记录事实结算。
- [ ] E-AC07：人工声明无默认选择，绑定当前文件/声明版本；身份不明、Page 已丢失或权限撤销时不会自动继续。
- [ ] E-AC08：关闭所有前端观察页，重试、恢复与终结仍能推进；人工/核对等待有界，耗时区间可复算。

## 范围外与交接

本项不做 AI 异常推理、验证码绕过、自动声明、强制接管其他活跃浏览器或跨机恢复 Page。向 T3 交付可安全重复准入的服务与恢复扫描；向 T4 交付错误投影、attempt/等待统计和人工操作能力标志。平台原始报价性质保持。
