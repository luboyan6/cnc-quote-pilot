# 产品配置自动报价

## Goal

用户在图纸参数配置列表逐行发起自动报价：访问该配置绑定的平台，复用有效登录态或完成登录，上传关联图纸，应用该行加工参数，最终在弹窗展示平台返回的报价。

## Background and confirmed facts

- 用户于 2026-10-23 授权创建任务并进入规划，并同意账号选择规则：一个可用账号时自动使用，多个时弹窗选择；尚未进入实施阶段。
- 入口为 `frontend/web/src/views/module_cnc/cnc_part_config/index.vue`，当前只有详情、编辑、删除操作。该文件已有用户未提交修改，后续必须保留。
- `frontend/web/src/api/module_cnc/cnc_part_config.ts` 的配置含 site_type、part_id、material、quantity、surface_finish、extra_params；没有 account_id。
- 当前页面 `index.vue:190` 使用真实平台记录 ID 作为 site_type 的值；后端旧注释中的 1/2 枚举不作为本次适配器选择依据。
- `backend/app/plugin/module_cnc/cnc_account/model.py` 的账号按 platform_id 关联平台，现有结构允许同平台多账号。账号操作有所属用户权限边界，不能随意取另一用户的账号。
- `frontend/web/src/views/module_cnc/cnc_account/useAccountLogin.ts` 与 `backend/app/modules/cnc/login/` 已实现受控浏览器登录、有效状态复验、人工挑战及加密状态复用。登录支持范围为 Xometry US、嘉立创 CNC。
- `backend/app/modules/cnc/browser/contracts.py` 只有 PlatformAdapter、IntentStore 协议；`workflow.py` 是共用校验组件，没有可直接调用的真实平台上传/配置/报价适配器。此次需要前后端完整功能，不能仅增加按钮并调用登录接口。
- 相关历史约束见 `.trellis/tasks/10-21-cnc-mvp-02-first-quote/prd.md`、`account-login-design.md` 与父任务 decisions.md 的 D-17/D-18：Xometry 优先、嘉立创随后、RapidDirect 延期；真实报价门槛尚未通过。已有登录能力通过自动化检查，真实平台认证曾因公网 DNS 出站校验阻断而未验收。历史阻断不等于本轮已重测，完整报价实施前须协调原任务范围与进入条件。

## Requirements

- R-01：在每行末尾操作区增加“自动报价”入口，目标为该行配置及其关联图纸。
- R-02：平台入口从关联平台读取；复用账号模块的受控登录能力。已有有效登录态直接进入报价流程；未登录时登录，验证码等需要人工操作时展示受控页面，验证通过后才能继续。
- R-03：上传该配置关联的图纸文件，并设置加工材料、数量、表面处理及适用的差异化参数；不得静默替换用户参数。无法匹配或不支持时明确说明。
- R-04：弹窗展示该次平台返回的报价及必要上下文；币种、单价/总价性质、平台参考估价/待审核等状态必须准确区分，不能以旧价、目录价或参考估价冒充真实报价。
- R-05：保留现有列表、CRUD、图纸与平台选择功能及未提交修改；遵守账号权限、凭据保护与同账号浏览器互斥规则。
- R-06（用户已确认）：该平台只有一个有权使用且启用的账号时自动使用，多个时弹窗选择；没有可用账号时提示先配置。此次不增加配置与账号的永久绑定。
- R-07：弹窗反馈准备、登录、上传、解析、填参、取价阶段；人工挑战时允许操作同一受控页面，复验后续跑，自动阶段避免人工并行改参。关闭或离开页面停止运行并释放其持有的浏览器；再次打开不能自动重发未确认操作。
- R-08：按既有顺序先接通 Xometry US，再接通嘉立创 CNC，两站分别验收。图纸须符合已有上传授权和文件校验规则，平台无订单副作用的报价路径须完成技术核验后才开放。

## Acceptance Criteria

- [ ] AC-01（R-01/05）：每行可以发起其自身的自动报价，执行中有状态反馈，不串用其他配置或图纸。
- [ ] AC-02（R-02）：未登录进入登录流程；已有有效会话不重复提交凭据；人工挑战复验通过后继续。账号或平台不可用时给出明确原因。
- [ ] AC-03（R-03）：平台实际收到对应图纸，已应用参数与该行配置一致；参数不匹配不返回成功。
- [ ] AC-04（R-04）：成功后弹窗展示同次返回价格和币种等信息；参考估价、人工审核、失败单独反馈，不伪造成功。
- [ ] AC-05（R-05）：既有 CRUD、权限与隐私行为保持，自动化检查与真实平台验证分别报告。
- [ ] AC-06（R-06）：分别验证零个、一个、多个可用账号的反馈/自动选择/弹窗选择行为，不能选择其他平台或越权账号。
- [ ] AC-07（R-07）：阶段清晰、挑战通过后同一运行继续；重复点击、关闭、重开和未确认回执不产生盲目重复上传或报价请求。
- [ ] AC-08（R-08）：Xometry 与嘉立创分别提供关联图纸、实际有效参数和同次结果的证据；平台受阻或仅返回参考估价如实报告，不替代真实报价验收。

## Out of scope

不包含批量/定时询价、下单或支付、RapidDirect、永久账号绑定、通用后台改造或完整 MVP 的异常 Agent 与跨平台对比。既有完整 MVP 验收不由本次按钮集成替代。
