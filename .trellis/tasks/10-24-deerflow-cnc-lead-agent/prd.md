# DeerFlow Lead Agent 源码融合

> 2026-10-29 后续实施授权：用户要求实现全部 Agent 升级任务，本子任务已进入实施；以下计划阶段范围描述保留为历史记录。

## 目标与背景

以 DeerFlow 的必要图组装、技能和中间件源码为基础，在当前 FastAPI 内实现本地异步 Agent 服务，融合现有认证、个人模型、数据库与 CNC 服务。
本任务为聊天的前置；2026-10-29 本轮只更新计划。架构以 [源码映射](../10-24-deerflow-cnc-agent/research/source-integration-replan-2026-10-29.md) 为准，不继续官方 Client-only 方案。

旧自建运行层在 10-27 已清理，原 SC-01/03 清理完成与 SC-02 回归未全绿的事实保留于 [清理报告](research/cleanup-validation-2026-10-27.md)，不当作新源码融合验收。
当前 CNC 业务已具备查询/报价/批次/监测/结果基础；本任务先接安全只读能力，不重建业务底座。

## 需求

- L-01：必要源码按项目职责重组，保留可追溯来源、许可证和实际行为；不能整目录移入或恢复旧代码冒充移植。
- L-02：适配后的技能目录、详情、按需激活及允许工具集合一致；只读查询/状态走现有 CNC Service。
- L-03：当前数字用户身份/权限和个人模型保持隔离，ID/地址/密钥/温度不被静默替换；凭据不入模型工具、事件或持久状态。
- L-04：原生异步图执行支持首 token 前及流中停止、超时、断线和服务退出，取消真实释放本地生成资源，终态唯一。
- L-05：业务幂等、防未知写入与后台任务生命周期继续由 CNC Run/Intent 负责，停止生成不撤销已准入业务。
- L-06：采用最小框架依赖、标准持久 checkpoint 和本项目 lifespan/设置/日志；旧 Agno 可用，未选的上游平台能力不引入。

## 后续验收

- [ ] LA-01（L-01/02）：实际运行适配后的图，加载已发布 CNC 技能并通过本地工具查询本人真实业务；来源组件与行为测试可核对，真实模型验收独立记录。
- [ ] LA-02（L-02/03）：目录/执行一致；无效技能、未实现工具、越权对象/伪造身份在业务执行前拒绝，撤权即时生效。
- [ ] LA-03（L-03）：两用户并行模型/会话隔离；模型选择与个人配置一致，凭据不进 checkpoint/消息/流/日志。
- [ ] LA-04（L-04）：首 token 前、慢流、工具等待、停止/超时/断线/shutdown 有可等待清理证据；stop 进入后 1 秒内确认并结束本地生成，无重复终态或后台残留模型 Task。
- [ ] LA-05（L-05）：重放/换工具 ID/新会话/不确定回执不重复业务写入；聊天停止后已准入领域任务继续，业务取消另行授权。
- [ ] LA-06（L-01/06）：来源/许可证和最小依赖可复现，PostgreSQL checkpoint 重启续聊及应用清理通过；局部 lint/type/tests 与旧聊天回归通过，没有 DeerFlow 运行时或同级路径依赖。

## 范围外与依赖

本轮不实施、安装、迁移、调用模型或平台；任务保持 planning。
后续不移植完整 DeerFlow 包、Client、Gateway、上游配置/鉴权/ORM/RunManager、沙箱、长期记忆、通用文件/Shell/浏览器工具或子 Agent 委派；不重建 AgentRun/ToolOperation。
报价写能力与批量/监测工具由后续子任务交付。旧历史/会话 CRUD 的产品迁移由聊天任务负责，本任务只确定状态/事件/资源契约及先行样本。
